# Egg-Catcher-Game-using-Python-OpenGL-3D-
**🐣 Chicken Egg Catcher 3D**  Five chickens, one basket — catch the eggs, dodge the bombs. Golden eggs score big, freeze eggs slow things down, and multi eggs flood the screen with gold. Grab power-up stars for shields and magnets. Keep your combo alive across ten brutal levels before you lose all three lives.
